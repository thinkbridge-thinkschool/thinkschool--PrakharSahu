 2. The broker gets past that gate, and runs into the next one
============================================================================================

  Same request, one hop earlier. The broker attaches its managed-identity token in

  X-Caller-Token, so the caller check passes. The USER check does not: Day 27 made

  authentication the fallback policy, so an endpoint is authenticated unless it says otherwise.

  Two independent gates, and this proves the second one is real rather than implied.

============================================================================================

============================================================================================
 8. The debug levers are NOT here, and that is the point
============================================================================================

  Days 21 and 22 built endpoints that hold the circuit breaker open and switch the cache off.

  They are instrumentation, and they are levers over the application's behaviour. Day 27 made

  them Development-only rather than merely authenticated, because an endpoint that does not

  exist cannot be misconfigured. So the resilience demo cannot be run against production -

  a real cost of a decision that was still right.

      POST /api/v1/cache/mode -> HTTP 404
  [pass] 404 - not mapped in Production. The lever is absent, not guarded

 9. Dispatch — the money path, end to end, against a real clock
============================================================================================

  Raise, triage, schedule, start, log labour, complete, invoice. Three modules, one process,

  no distributed transaction anywhere. The window is opened three seconds from now because

  the rule that work cannot start early only means something against a real clock.

      POST /api/work-orders -> HTTP 201   id=01a0b346-f97b-7940-9994-61feeb1b07d0
